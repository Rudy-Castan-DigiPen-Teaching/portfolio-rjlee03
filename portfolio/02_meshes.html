Project Procedural Geometric Modeling

3D Graphics

Project Overview

This project is the second assignment for CS250 Computer Graphics II at DigiPen Institute of Technology. The goal was to procedurally generate six 3D geometric primitives — Plane, Cube, Sphere, Torus, Cylinder, and Cone — using parametric equations, and render them with OpenGL using textured materials, wireframe overlays, and normal visualization.

The project builds on the rendering pipeline from the Hello Quad assignment, adding a Material system, a Mesh abstraction with SubMeshes, and an index buffer–based rendering approach. All meshes are generated at runtime with configurable stacks and slices parameters.

Tasks Completed

  • build_index_buffer — Implemented the shared index buffer generator that creates triangle pairs (two triangles per grid cell) for any stacks × slices grid.
  • create_plane_vertices — Generated a flat plane mesh with positions centered at the origin, uniform normals facing +Z, and UV coordinates mapped across the surface.
  • create_sphere — Implemented sphere generation using spherical coordinates (beta/alpha) to map stacks and slices into 3D positions with proper normals.
  • create_torus — Implemented torus generation with major radius R=0.35 and minor radius r=0.15, using angle interpolation for partial or full torus shapes.
  • add_cap — Implemented triangle fan cap generation for the top and bottom of cylinders and cones, with correct winding order based on cap direction.
  • create_cylinder — Generated cylinder body vertices with side-facing normals, then added top and bottom caps using the add_cap helper.
  • create_cone — Generated cone vertices with a tapering radius from bottom to tip, computed tangent-based normals for smooth shading, and added a bottom cap.
  • convert_to_lines_pattern — Converted triangle index buffers into line pair indices for wireframe rendering, handling both quad-pair and individual triangle patterns.

Reflection

The most challenging part of this assignment was understanding the parametric equations for the torus. Getting the major and minor radius relationships correct, along with the normal calculation using the center offset, required careful attention to the math. Debugging was also tricky since incorrect normals are hard to spot visually without the normal visualization feature.

Through this assignment, I gained a much deeper understanding of how 3D meshes are constructed from vertices and indices. I learned how the same index buffer pattern can be reused across different shapes, and how caps require a different triangle fan approach compared to the grid-based body. Working with the Material system also gave me experience with shader uniforms and texture management in a more structured way.
